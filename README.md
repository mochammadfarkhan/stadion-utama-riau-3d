# Stadion Utama Riau — Simulator 3D

Simulator 3D interaktif Stadion Utama Riau (Pekanbaru) dibangun dengan [Three.js](https://threejs.org) + Vite.

Fitur:
- Bersepeda keliling kawasan stadion (dalam & luar) dengan kontrol fisika sederhana
- Pedagang minuman & buah keliling (gerobak) yang bisa diajak transaksi
- Pemain sepak bola NPC bertanding di lapangan
- Pelari di tiap lane lintasan atletik 400 m
- Detail lingkungan: tribun 40.000 kursi (instanced), atap membran oval, fasad louvre Melayu, selembayung, plaza, parkir, danau, monumen Lancang Kuning, bangku, lampu, tempat sampah, dll.

## Menjalankan
```bash
npm install
npm run dev
```

## Test
```bash
npm test
```
