# Indeks plan: Kawasan Kampus UNRI (M0–M7)

Spec: `docs/superpowers/specs/2026-10-17-unri-kampus-design.md` (kontrak §4 mengikat).
Katalog aset: `docs/superpowers/specs/2026-10-17-unri-asset-catalog.md`.
Riset: `docs/research/kampus-unri-bina-widya.md`. Branch: `feat/unri-kampus`.

Dokumen ini **mengunci peta file dan antarmuka antar tonggak** agar delapan plan konsisten. Plan tonggak N
boleh memakai apa pun yang dibuat tonggak < N **persis dengan nama di sini**. Menambah file baru di dalam
tonggaknya sendiri boleh; mengubah nama/kontrak di bawah tidak boleh tanpa mengubah indeks ini.

## Aturan eksekusi (semua plan)

- Eksekusi per tonggak oleh **satu implementer**, **satu review** di akhir tonggak (memori user
  `lightweight-process-hobby`). Tes (TDD: tulis tes → gagal → implementasi → lulus) **hanya** untuk logika
  murni/berisiko yang disebut di spec §11. Kode visual: implementasi + smoke (dev server/Playwright) + screenshot.
- Perintah tes cepat di Windows: `node node_modules/vitest/vitest.mjs run <path>` (bukan `npx`).
- Lint: `npm run lint`; build: `npm run build`; E2E: `npm run e2e -- --gpu d3d11`.
- Commit: jalankan `git add <file…>` lalu **perintah terpisah** `git commit -m "<pesan>"` (hook `block-no-verify`
  salah memblokir commit yang digabung dengan perintah lain). Format conventional commit, bahasa Indonesia.
- Bahasa: kode, komentar, pesan commit, teks UI dalam bahasa Indonesia (mengikuti repo).
- Dev server untuk cek visual: `preview_start` nama `stadion-dev` (`.claude/launch.json`), atau Playwright ke
  `http://localhost:5173`; `window.__sim` (DEV) berisi app/ents/rig/store/teleport.
- Panel Browser bawaan sering tersembunyi (rAF berhenti): screenshot/ukur pakai Playwright GPU.
- Setiap akhir tonggak: `npm test` hijau, `npm run lint` 0 galat, `npm run build` sukses, screenshot titik ukur
  tonggak ke `docs/screenshots/unri/mN-*.jpg`, dan baris status di bagian "Status tonggak" di bawah diperbarui.
